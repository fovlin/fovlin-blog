---
title: 使用 Geyser 允许基岩版进入
description: 使用 Geyser 实现 Java 版与基岩版互通
lastUpdated: 2026-01-14
---

Geyser 插件/核心对后端服务器创建一个反向代理，基岩版玩家可以通过此层代理连接到 Java 服务端实现 Java 版与基岩版的互通。

## 下载 Geyser 插件/核心
Geyser 有两种版本，一种是插件/ mod 版，跟随服务端启动，一种是独立的服务器核心，推荐使用 Velocity 代理搭配适配于 Velocity 的 Geyser 插件版，这种方法便于管理，且不用考虑 Geyser 对后端服务器核心的适配性，让 Velocity 完成一切！

- 前往 [GeyserMC 官网](https://geysermc.org/) 下载 Geyser Jar 文件

- 将 Jar 文件放入服务端的 plugins 目录

## 配置 Geyser
需要启动一次服务端来生成 Geyser 的配置文件。

- 对于模组端，配置文件位于 `config` 目录下，寻找含有 Geyser 的相关的目录或配置文件。

- 对于插件端，配置文件位于 `plugins` 目录下，寻找含有 Geyser 的相关的目录或配置文件。

:::tip
不同核心对应的 Geyser 配置文件所在的目录名称可能会有所，例如 Velocity 版本的配置文件位于 `plugins/Geyser-velocioty/config.yml`。
:::

- 编辑配置文件，下面介绍配置文件中较重要的选项。

```yml
bedrock:

    address: 0.0.0.0
    # 监听的IP地址，0.0.0.0代表本机所有IP地址。
    port: 19132
    # Geyser 监听端口，基岩版玩家将通过此端口连接到 Geyser 代理。
    clone-remote-port: false

java:
    auth-type: floodgate
    # 对基岩版玩家的 Java 验证类型，有以下三个可选项。
    # offline 代表离线，不验证，若服务器启用了正版验证，基岩版玩家会无法登入。
    # online 代表验证玩家是否拥有 Java 正版账号。
    # floodgate 可以在服务器开启正版验证的情况下，允许基岩版玩家进入。
    # 其中 foodgate 需安装 Floodgate 插件。
```
:::tip
推荐使用服务器正版验证+Floodgate 插件，可提高服务器安全性。
:::

## 连接！

- 重新启动服务端，在基岩版服务器-添加服务器中输入IP地址及 Geyser 的端口，即可连接到 Java 版服务器。
