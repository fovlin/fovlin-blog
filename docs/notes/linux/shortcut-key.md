# Linux 常用快捷键

> 以 bash 和常见终端为准；不同终端模拟器可能还有自己的快捷键。

## 命令行编辑

### 光标移动

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + A` / `Home` | 移到行首 |
| `Ctrl + E` / `End` | 移到行尾 |
| `Ctrl + F` / `→` | 前进一个字符 |
| `Ctrl + B` / `←` | 后退一个字符 |
| `Alt + F` | 前进一个单词 |
| `Alt + B` | 后退一个单词 |
| `Ctrl + XX` | 在当前位置和标记之间跳转，常用来回行首 |

### 删除与粘贴

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + U` | 删除光标到行首 |
| `Ctrl + K` | 删除光标到行尾 |
| `Ctrl + W` | 删除光标前的一个单词 |
| `Alt + D` | 删除光标后的一个单词 |
| `Ctrl + D` | 删除光标处字符；空行时表示 EOF 或退出 |
| `Ctrl + H` / `Backspace` | 删除前一个字符 |
| `Ctrl + Y` | 粘贴最近删除的内容 |

### 大小写与交换

| 快捷键 | 作用 |
| --- | --- |
| `Alt + U` | 当前单词转为大写 |
| `Alt + L` | 当前单词转为小写 |
| `Ctrl + T` | 交换光标前后的两个字符 |
| `Alt + T` | 交换光标前后的两个单词 |

### 撤销与清屏

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + -` / `Ctrl + X + U` | 撤销命令行编辑 |
| `Ctrl + L` | 清屏并保留当前输入 |

## 历史命令

### 浏览与搜索

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + P` / `↑` | 上一条历史命令 |
| `Ctrl + N` / `↓` | 下一条历史命令 |
| `Ctrl + R` | 反向搜索历史 |
| `Ctrl + G` | 退出历史搜索 |

### 历史展开

| 写法 | 作用 |
| --- | --- |
| `!!` | 执行上一条命令 |
| `!num` | 执行第 num 条历史命令 |
| `!string` | 执行最近以 string 开头的命令 |
| `!?string?` | 执行最近包含 string 的命令 |
| `!$` | 取上一条命令的最后一个参数 |
| `!*` | 取上一条命令的所有参数 |
| `!string:p` | 只打印命令，不执行 |
| `!num:gs/old/new/` | 替换第 num 条命令中的字符串 |
| `^old^new` | 把上一条命令中的 old 替换为 new 并执行 |

## 终端控制

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + C` | 中断当前命令 |
| `Ctrl + Z` | 挂起当前命令，可用 `fg` 恢复、`bg` 放到后台 |
| `Ctrl + S` | 暂停终端输出 |
| `Ctrl + Q` | 恢复终端输出 |
| `Ctrl + L` | 清屏 |
| `Ctrl + D` | 发送 EOF；在空提示符下退出 shell |
| `Ctrl + 反斜杠` | 发送 SIGQUIT，强制退出进程，可能产生 core dump |

## 桌面环境

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + Alt + F1` 到 `F6` | 切换到对应的 tty |
| `Ctrl + Alt + Delete` | 重启系统 |
| `Alt + Tab` | 切换窗口 |
| `Ctrl + Alt + Backspace` | 结束 X 会话，部分发行版默认禁用 |

## Esc 组合键

| 快捷键 | 作用 |
| --- | --- |
| `Esc` 连按 3 次 | 列出所有可补全命令 |
| `Esc + B` / `Esc + F` | 按单词后退 / 前进 |
| `Esc + T` | 交换光标前两个单词 |
| `Esc + D` | 删除光标后的单词 |
| `Esc + C` | 当前单词首字母大写并前进 |
| `Esc + U` | 当前单词转为大写并前进 |
| `Esc + .` | 插入上一条命令的最后一个参数 |
| `Esc + 数字 + 操作` | 重复执行指定操作若干次 |
