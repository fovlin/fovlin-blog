# Linux 命令行基础

这一章整理日常最常用的命令行操作：文件管理、输入输出重定向和进程管理。每一节都按“先会用、再理解”的顺序展开，示例可以直接复制到终端里练习。

## 文件管理

这一节从最常用的文件操作开始，涵盖 [ls](#ls-命令)、[mkdir](#mkdir-命令)、[cp](#cp-命令)、[rm](#rm-命令)、[touch](#touch-命令)、[chmod](#chmod-命令)、[chown](#chown-命令) 和 [nano](#nano-命令)。

### ls 命令

`ls` 用于列出目录内容，也可以配合通配符筛选文件。

用法：

```txt
ls [option] <路径>
```

常见选项如下：

- `-a`：同时列出隐藏文件

- `-l`：显示详细信息

- `-h`：以 MB、GB 等更易读的单位显示大小，通常和 `-l` 一起用

查看 `/etc` 目录下的文件：

```bash
ls /etc
```

查看当前目录下的所有文件，含隐藏文件：

```bash
ls -a
```

查看上级目录下文件的详细信息，并以 MB 或 GB 的文件大小计数方式列出所有文件，含隐藏：

```bash
ls -alh ../
```

### mkdir 命令

`mkdir` 命令用于创建目录，用法如下：

```txt
mkdir [option] <路径>
```

常用选项：

- `-p`：递归创建，父目录不存在时自动创建

例如创建 `video` 目录：

```bash
mkdir video
```

递归创建一系列文件夹：

```bash
mkdir -p one/two/three
```

### cp 命令

`cp` 命令可以复制一份文件或目录到指定的路径。语法如下：

```txt
cp [option] <文件路径> <目标路径>
```

选项说明：

- `-r`：递归复制目录及其内容（用于复制目录）。

- `-i`：交互模式，覆盖前提示用户确认。

- `-f`：强制复制，覆盖目标文件而不提示。

- `-v`：显示详细的复制过程（verbose）。

- `-p`：保留文件的原始属性（如权限、时间戳等）。

- `-a`：归档模式，等同于 `-dpr`，保留所有文件属性和递归复制目录。

- `-u`：仅当源文件比目标文件新时才复制（更新模式）。

- `-l`：创建硬链接而不是复制文件。

- `-s`：创建符号链接（软链接）而不是复制文件。

例如把 `/home/fovlin/file` 复制到 `/home/fovlin/Documents/`：

```bash
cp /home/fovlin/file /home/fovlin/Documents/
```

复制当前工作目录下的 `directory` 目录到 `/home/fovlin/Documents` 目录下：

```bash
cp -r ./directory /home/fovlin/Documents
```

### rm 命令

`rm` 命令可以删除一个或多个文件或目录。

用法：

```txt
rm [option] <路径>
```

常见选项如下：

- `-r`：递归删除，删除目录时必需

- `-f`：强制删除，忽略不存在的文件且不提示

- `-i`：交互式删除，删除前逐一询问确认

> `rm -rf` 不会进入回收站，执行前务必确认路径。

删除单个文件：

```bash
rm file.txt
```

递归删除目录及其内容：

```bash
rm -rf dir/
```

交互式删除文件：

```bash
rm -i file.txt
```

### touch 命令

`touch` 命令用于创建空文件，或更新已有文件的时间戳。

用法：

```txt
touch [option] <路径>
```

常见选项如下：

- -c：不创建文件，仅更新时间戳

- -t：使用指定时间而非当前时间

创建一个空文件：

```bash
touch newfile.txt
```

同时创建多个文件：

```bash
touch file1.txt file2.txt file3.txt
```

仅更新文件时间戳，不创建：

```bash
touch -c existing.txt
```

### chmod 命令

使用 `ls -l` 命令时，会输出文件的基本信息，其中包含文件的权限信息：

```log
drwxr-xr-x  2 fovlin fovlin 4096  4月17日 00:37 docs
```

从左到右依次是：文件类型与权限、硬链接数、所有者、所属组、文件大小、最后修改时间、文件名。目录的大小通常不显示实际占用空间。

#### 更改文件权限

文件权限 `drwxr-xr-x` 前一个字符表示文件类型，常见字符对应的文件类型如下：

- `-`: 普通文件

- `d`: 目录

- `l`: 链接

- `c`: 字符设备文件

- `b`: 块设备文件

- `s`: 套接字文件

- `p`: 管道文件

文件权限 `drwxr-xr-x` 的第 2–4、5–7、8–10 个字符分别表示所有者、所属组和其他用户的权限，每个字符代表：

- `r`: 读权限

- `w`: 写权限

- `x`: 执行权限

使用 `chmod` 可以改变文件权限，用法如下：

```txt
chmod [选项] <权限信息> <文件名>
```

> 权限不足时，在命令前加 `sudo` 以管理员身份执行。

也常用数字模式表示权限：

- `x`: 1

- `w`: 2

- `r`: 4

将需要的权限对应的数字加和即可表示单个权限。

权限也可以用三位八进制数字表示，依次对应所有者、所属组和其他用户。例如 `751` 表示所有者 `rwx`、所属组 `r-x`、其他用户 `--x`：

```bash
chmod 751 script.sh
```

对整个 `docs` 目录递归应用同样的权限：

```bash
chmod -R 751 docs
```

> 对目录来说，`x` 权限表示能否进入该目录。

### chown 命令

`chown` 命令用于更改文件的所有者，格式如下：

```txt
chown [option] <所有者|所有者:所属组> <文件路径>
```

- `-R`：--recursive，递归更改目录及其子目录中所有文件的所有者

- `-v`：--verbose，显示详细操作信息

- `-c`：--changes，只显示实际发生更改的文件

- `-f`：--silent, --quiet，抑制错误信息

- `--reference=文件`：使用参考文件的所有者和组设置

- `-h`：--no-dereference，影响符号链接本身，而不是链接指向的文件

- `--from=当前所有者`：只有当前所有者匹配时才更改

使用 `ls -l` 命令时，会输出文件的基本信息，其中包含文件的权限信息：

```log
drwxr-xr-x  2 root root 4096  4月17日 00:37 docs
```

`root root` 分别是所有者和所属组，修改它们需要用到 `chown`。

更改不属于自己的文件需要管理员权限。例如把当前目录下 `docs` 及其内容的所有者和所属组都改为 `fovlin`：

```bash
sudo chown -R fovlin:fovlin docs
```

### nano 命令

`nano` 是一个简单的文本编辑器，直接运行 `nano <文件路径>` 即可开始编辑。

开始编辑后，会进入交互式命令行模式，常用快捷键如下：

- `Ctrl + G`：帮助

- `Ctrl + O`：写入文件

- `Ctrl + F`：搜索字符串

- `Ctrl + K`：剪切

- `Ctrl + T`：执行命令

- `Ctrl + X`：离开

- `Ctrl + R`：读档

- `Ctrl + \`：替换

- `Ctrl + U`：粘贴

- `Ctrl + J`：对齐

nano 的修改先保存在缓冲区，退出前需要按 `Ctrl + O` 写入文件，再按 `Ctrl + X` 退出。

诸如此类的工具还有 `vim` `neovim` 等。

## 输入/输出重定向

重定向可以把命令的输入、输出连接到文件或其他命令，而不必经过屏幕。

### 输出重定向

在终端中，可以用 `>` 或 `>>` 把输出写入文件：`>` 覆盖原文件，`>>` 追加到文件末尾。

```txt
command > file
```

例如，`echo` 命令将输出指定的变量或字符串，可以通过输出重定向快速写入内容到文件，例如想在 `.bashrc` 的尾行加入一条内容 `alias ll='ls -lh --color=auto'`：

```bash
echo "alias ll='ls -lh --color=auto'" >> ~/.bashrc
```

这将在尾行追加该内容，你也可以使用 `>` 覆盖整个文件。

### 输入重定向

用 `<` 把文件内容作为命令的标准输入：

```txt
command < file
```

`wc -m` 用于统计字符数。通过 `<` 把文件内容作为标准输入传给它：

```bash
wc -m < README.md
```

这和 `wc -m README.md` 的结果相同，区别只在于输入来源：前者从标准输入读取，后者由 `wc` 自己打开文件。

### 重定向文件描述符

文件描述符是进程用来标识已打开文件的整数。

在 Unix 和 Linux 系统中，每个进程在启动时会自动打开三个标准的文件描述符：

- `0`：标准输入（stdin）

- `1`：标准输出（stdout）

- `2`：标准错误（stderr）

使用 `n>` 指定要重定向的文件描述符，其中 `n` 是文件描述符编号。

例如把错误信息写入 `error.log`：

```bash
command 2> error.log
```

同样，`n>>` 表示追加而不是覆盖。

### Here Document

使用 `<<` 可以把一段文本作为命令的标准输入。结束标记可以自定义，下面的例子使用 `maker`：

```txt
$ wc -m << maker
> Acovia docs
> maker
12
$ 
```

### 组合重定向

如果你希望将多个文件描述符的内容写入文件，可以组合写入，格式如下：

```txt
command > out.log 2>&1
```

`2>&1` 表示把标准错误重定向到标准输出当前指向的位置；顺序会影响最终结果，通常写成 `> out.log 2>&1`。

## 进程管理

在命令行中查看并管理进程。

### 查看 PID

查看进程最常见的方式是用 `ps` 或 `top` 系列命令。`ps` 适合脚本和快速查询，`top` 系列更适合交互式观察。

#### ps 命令

Linux 会为每个进程分配一个 PID 作为唯一标识。`ps -e` 列出所有进程，`ps -ejH` 或 `pstree` 可以查看树状结构；也可以把输出通过管道交给 `grep` 筛选。

查询包含 `code` 字符串的进程：

```bash
ps -e | grep -i code
```

> `grep -i` 表示忽略大小写。

例如产生以下输出：

```txt
   3289 ?        00:00:37     code
   3292 ?        00:00:00       code
   3337 ?        00:00:59         code
   3293 ?        00:00:00       code
   3295 ?        00:00:00         code
   3379 ?        00:03:21           code
   3339 ?        00:00:01       code
   3412 ?        00:00:06       code
   3498 ?        00:00:02       code
   3511 ?        00:00:27       code
   3608 ?        00:00:00         code
   3627 ?        00:00:06         code
```

如果这些进程属于同一个应用，通常操作主进程即可；但子进程可能需要单独处理。

更多用法可以查看 `man ps` 或 `ps --help`。

#### top 系列命令

常见的 top 系列工具有 `top`、`htop`、`btop`、`atop` 等。`htop` 实用、易上手；`btop` 界面更漂亮，但对终端窗口大小有要求。除 `top` 外，多数发行版需要手动安装这些工具。下面以 `htop` 为例：

```bash
htop
```

运行后会显示所有进程的 PID、CPU 和内存占用等信息，也可以直接用键盘查找或操作进程。

### 查看资源占用

`htop` 已经能显示 CPU、内存、线程数和 PID 等常用信息。针对特定资源，还有更专门的命令。

#### 内存占用

`free` 命令查看运行内存占用情况，常用以下命令进行查看：

```bash
free -h
```

`-h` 会以 MB、GB 等更易读的单位显示。

#### 查看流量进出速度

使用 `nload` 可以查看网卡的实时进出流量；它通常需要单独安装。

#### 查看端口占用情况

`lsof` 可以查看端口占用：

```bash
sudo lsof -i:端口号
```

`netstat` 包含在 `net-tools` 软件包中，多数发行版默认不安装。使用 `-tunlp` 可以列出所有监听中的 TCP/UDP 端口，再通过管道交给 `grep` 过滤：

```bash
netstat -tunlp | grep <端口号>
```

### 结束进程

结束进程常用两种方式：按 PID 使用 `kill`，或按进程名使用 `pkill`。

#### kill 命令

`kill` 向进程发送信号，默认发送 SIGTERM。格式为 `kill [-信号] PID`，常用信号如下：

- `SIGKILL`（信号 9）：立即结束进程，不能被捕获或忽略。

- `SIGTERM`（信号 15）：请求进程正常退出，可以被捕获或忽略。

- `SIGINT`（信号 2）：通常由 `Ctrl + C` 产生，可以被进程捕获或忽略。

例如查到 `code` 的 PID 为 3389，结束它：

```bash
kill 3389
```

或指定信号，强制结束：

```bash
kill -9 3389
```

#### pkill 命令

`pkill` 按进程名匹配并发送信号。例如结束名为 `code` 的进程：

```bash
pkill code
```

有时进程名过长，可以使用 `-f` 选项杀掉所有包含某个字符串的进程名的进程，例如杀掉 `prismlauncher` 进程可以使用如下命令：

```bash
pkill -f prism
```

### 接管进程

`reptyr` 可以把一个正在运行的进程从其他终端接管到当前终端。它通常需要额外的 ptrace 权限设置，使用前请先查看发行版文档。

```bash
reptyr <pid>
```
