# ? ? ?

梦里总是那样寂静，却又那样的真实，它们告诉我这里就是美好的现实，一切在变好，可当这里消失，它们然后连同我的灵魂，一同拽入深渊。

那一刻是那么的割裂，整个世界仿佛静止了。

我试图在现实中找到那片乐土，即便我脚踏着和梦里一模一样的土地，但这里没有那片土地的魔力...

啊啊...现实和梦里差别总是这么大，真希望做一场永远不会醒来的梦啊，那里不用思考任何事情，即便没有感官，灵魂也可以得到真正意义上的休息。

他们总说，快乐的最佳方式是在苦中做乐，但...我始终没办法在这令我窒息的世界中找到持久的快乐，我快乐吗？我也不知道，明明有着不错的家庭条件，健康的身体，却仿佛那个摇摇欲坠的灵魂木偶随时都会断线一般。

当他们问及我想要什么...我也不知道，漫无目的地奔忙，连自己所追求什么都说不清楚。
