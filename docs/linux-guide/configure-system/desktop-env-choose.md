# 桌面环境

> 本文为桌面版 Linux 发行版教程，即便服务器 Linux 同样能安装桌面环境，但这违背了服务器系统轻量稳定的初衷。

在绝大多数的 Linux 发行版中，都自带了默认的桌面环境，如 Ubuntu、Debian、Fedora 默认的桌面环境为 GNOME。

## 选择桌面环境

关于桌面环境的选择本文不做过多赘述，可参考 Arch wiki 来了解各大桌面环境的特点。本文着重讲解如何配置一个图形化界面，即桌面环境。

## 启动桌面环境

桌面环境可以通过使用显示管理器来启动，也可以通过命令行从 tty 控制台启动，例如 kde 桌面环境，可以通过使用命令 `startplasma-wayland` 或 `startplasma-x11` 来启动，此处推荐使用前者，Wayland 是更为稳定、现代化的显示服务器，而相对的 X11 虽然兼容性较强，但已知的 bug 较多。

## 显示管理器

窗口管理器是的登录进入桌面环境提供的图形化界面方式，例如 Gnome 默认的显示管理器是 GDM，KDE 默认的显示管理器是 SDDM，但 KDE 官方在 26.02 新推出了一个名为 `plasma-login-manager` 的显示管理器。这些显示管理器仅被用作登入和启动桌面环境，启动特定的桌面并不限制于这些显示管理器。

当然显示管理器并不止局限于这些。

## 字体

如果不满足默认的字体样式，可以安装其他字体来替代现有的字体，安装方式可以通过包管理器安装，或者下载字体文件，解压后安装。

关于下载字体文件手动安装的过程，下载字体的文件，解压后，将字体文件复制到 `/usr/share/fonts/` 目录下即可。

对于终端等宽字体，此处推荐微软的 `Cascadia Code`。
